# Kod źródłowy odpowiadający wydaniu / Corresponding source code

PT Calendar Manager is distributed under GNU GPL version 3 or later.

Every installer or portable binary release must be accompanied by one of the
following, at no additional charge:

1. the exact `pt-calendar-manager-VERSION-source.zip` generated by the release
   script and offered next to the binary files; or
2. a clearly identified public repository tag containing the exact source,
   build scripts and packaging files used for that binary.

The source archive generated by `tools/build_release.ps1` intentionally omits:

- OAuth client configuration from `release-secrets`;
- user tokens and settings;
- virtual environments;
- temporary build and output directories.

An OAuth client configuration is deployment-specific and is not required to
study, modify or build the program. A developer can supply their own Google
OAuth desktop client configuration for testing.

The corresponding source includes the PyInstaller specification, Windows
manifest, version metadata, installer script and release automation required
to reproduce the distributed application.
