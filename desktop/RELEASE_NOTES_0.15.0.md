# PT Calendar Manager 0.15.0 — zmiany

- całkowicie przebudowano główne okno wokół natywnego paska menu Windows;
- usunięto wszystkie przyciski funkcyjne z głównego okna;
- zachowano dwie główne listy: dni miesiąca i wydarzenia wybranego dnia;
- Tabulator przełącza bezpośrednio między obiema listami;
- dodano menu: Kalendarz, Wydarzenie, Konto, Ustawienia i Pomoc;
- obok poleceń menu wyświetlane są dotychczasowe skróty klawiaturowe;
- dodano menu kontekstowe obu list pod `Shift+F10`;
- przeniesiono „O programie” z okna Ustawień do menu Pomoc;
- pasek stanu ma osobne pola dla komunikatu operacji i stanu konta Google;
- nagłówek miesiąca oraz nazwy paneli używają subtelnego systemowego koloru akcentu;
- nie wprowadzono własnej skórki ani ręcznie ustawionych kolorów tła;
- nie zmieniono logiki Google, cykliczności, danych użytkownika ani skrótów aplikacji.
