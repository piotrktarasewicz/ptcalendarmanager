# PT Calendar Manager 0.16.2

Wersja 0.16.2 porządkuje dostęp do pomocy programu.

- pomoc jest wyświetlana jako semantyczny dokument HTML w oknie aplikacji;
- tytuł ma poziom nagłówka 1, a rozdziały poziom nagłówka 2;
- zachowano dotychczasową kolejność i treść rozdziałów;
- skróty klawiaturowe nadal znajdują się blisko początku pomocy;
- ekran końcowy instalatora zawiera opcję „Otwórz pomoc i skróty programu”;
- instalator uruchamia jedną instancję aplikacji bezpośrednio w widoku pomocy;
- skrót Dokumentacja w menu Start otwiera ten sam dostępny widok;
- otwieranie pomocy nie zależy od skojarzeń plików `.txt` ani `.md` w Windows.
