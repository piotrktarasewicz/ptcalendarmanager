# Tymczasowe commity budowania Windows

Poniższe commity powstały w prywatnym repozytorium `piotrktarasewicz/womaiowe-terminy` wyłącznie po to, aby skompilować PT Calendar Manager na maszynie Windows. Nie zawierają kodu WOMAI przeznaczonego dla tego repozytorium.

- `e0d3b5d849221fdeb6a8b5a42e86486d3f9e2f45` — Build PT Calendar Manager 0.16.2 accessible help.
- `e07dd66faf8ee4b06a5a9fa5ae00d4a0d0b0e13f` — tymczasowy build PT Calendar Manager 0.16.3.
- `dfab063a8c5e7f17c6e1c7094fc375e1cedece53` — uruchomienie tymczasowego buildu.
- `ed395e6d5957af517dada128c653c6a905819b10` — dodanie znacznika rozpoczęcia buildu.
- `72f2847814d7c1a99056187956a65aa93059636d` — dodanie ręcznego uruchamiania buildu.
- `238229663fd2dd472b205c1b63e06d046f206a0b` — usunięcie tymczasowego procesu z repozytorium WOMAI.

Gotowy build 0.16.3 przeszedł 12 testów wydania, kontrolę architektury x64, cichą instalację oraz sprawdzenie konfiguracji OAuth. Artefakty końcowe znajdują się na gałęzi `archive/all-project-files`.
