# Archiwum plików projektu

Gałąź `archive/all-project-files` przechowuje zachowane pliki robocze i wydaniowe projektu, w tym:

- prototypy i źródła historycznych wersji;
- sumy kontrolne i plany testów;
- dodatki NVDA 1.0.2–1.0.4;
- instalatory, paczki przenośne i źródłowe wydań Windows 0.16.0–0.16.3;
- skrypty używane do wcześniejszych prób publikowania i budowania;
- zachowane, bezpieczne logi robocze;
- zanonimizowane kopie dwóch logów, które pierwotnie zawierały prywatne dane kalendarza rodzinnego.

Nie przeniesiono plików tymczasowych powstałych podczas pobierania archiwum. Nie opublikowano również tokenów użytkownika ani luźnego pliku konfiguracyjnego OAuth.
